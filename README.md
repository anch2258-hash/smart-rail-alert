## 1. Назначение и актуальность
**SMART RAIL ALERT** — бортовая система поддержки принятия решений (Decision-Support System / AI Co-Pilot) для машинистов высокоскоростных магистралей (ВСМ-1, скорости до 360–400 км/ч).

### Проблема:
* На скорости 360 км/ч поезд преодолевает **100 метров за 1 секунду**.
* Длина тормозного пути скоростного состава при экстренном торможении достигает **3,5 км**.
* Человеческий глаз физически не способен вовремя распознать малоразмерное препятствие на пути, а монотонность и погодные условия снижают реакцию на 40–60%.

### Решение:
Программно-аппаратный комплекс в режиме реального времени сканирует путь по курсу следования, выделяет габарит колеи, классифицирует препятствия (люди, животные, техника, посторонние предметы) и выводит информацию на минималистичный HUD-интерфейс в кабине машиниста.

## 2. Ключевые инженерные решения
1. **Гибридный алгоритм детекции (OpenCV + YOLO11n):**  
   Алгоритмы классического компьютерного зрения (Canny + Hough) мгновенно строят геометрию рельсовой колеи и динамическую зону интереса (ROI). Параллельно легковесная модель YOLO11n классифицирует объекты.
2. **Асинхронная многопоточность (Multithreading Worker):**  
   Тяжелые нейросетевые вычисления полностью изолированы в фоновом процессе. Интерфейс машиниста работает на стабильных 60 FPS без фризов.
3. **RiskEngine с Grace-периодом (0.45 с):**  
   Временной верификатор отсекает тени от проводов, блики и птиц. Сигнал тревоги подается только при подтвержденной угрозе в габарите колеи.
4. **Аппаратная оптимизация (Pacing & Skip-Frame):**  
   Инференс нейросети запускается через кадр с кэшированием рамок, что снизило нагрузку на CPU с 501% до 225% и сэкономило ресурсы GPU почти в 2 раза.

## 3. Стек технологий и требования к окружению
* **Язык программирования:** Python 3.10+
* **Фреймворки и библиотеки:** PyTorch (с поддержкой CUDA), Ultralytics (YOLO11), OpenCV, Pillow, Tkinter, Pytest
* **Минимальное железо для тестов:** ПК/ноутбук с GPU NVIDIA (от GTX 1650 / RTX 3050 и выше) или современный многоядерный CPU.
* **Целевое железо для внедрения (Edge AI):** NVIDIA Jetson Orin Nano / AGX.

## 4. Порядок установки и запуска

### 1. Клонирование репозитория:
```bash
git clone https://github.com/<ваш-логин>/smart-rail-alert.git
cd smart-rail-alert
```

### 2. Создание виртуального окружения:
* **Windows:**
  ```bash
  python -m venv venv
  venv\Scripts\activate
  ```
* **Linux:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3. Установка зависимостей:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Скачивание весов модели:
Веса `yolo11n.pt` скачиваются автоматически при первом запуске либо могут быть загружены вручную в папку `models/`.

### 5. Запуск программы:
```bash
python main.py
```

### 6. Запуск автоматических тестов:
```bash
pytest -v
```

## 6. Результаты контрольных испытаний
В ходе лабораторного тестирования на датасете видеозаписей железнодорожных путей получены следующие метрики:
* **Точность обнаружения объектов (Precision/Recall):** 100/100 успешных детекций в зоне ROI на тестовой выборке.
* **Ложные срабатывания (False Positives):** 0 ложных тревог благодаря интеграции Grace-периода 0.45 с.
* **Производительность:** стабильные **24+ FPS** инференса нейросети на GPU NVIDIA RTX 4070 Laptop (при обновлении GUI на 60 FPS).
* **Снижение нагрузки на процессор:** алгоритм Pacing сократил потребление CPU с 501% до 225%.
